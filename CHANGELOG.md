# Changelog

- **Фикс:** переключение языка на «Русский» после смены на другой язык не срабатывало — Zod-схемы локалей дублируются в каждом слое бандла (renderer/host/scheduler/5 preload'ов), пропатчены все (11 файлов)

## v2.0.0 — 2026-08-30

Нативная локаль ru-RU для ZCode **3.10.1** (build 6272) — полная переработка пакета.

- Третий язык в селекторе: System / English / **Русский** (китайский не затронут)
- **5 018 ключей** — 100% корпуса рендерера (чат, настройки, плагины, скиллы, MCP, субагенты, git, автоматизации, usage…)
- Fallback на английский для строк будущих версий апстрима — «голых» ключей не бывает
- Переведены описания встроенных агентов и стилей вывода (host-чанк, 5 строк)
- Переведены мелкие окна: мониторинг процессов, панель разрешений Computer Use
- Автодетект системной русской локали
- `install.sh` — установка одной командой с бэкапом, проверкой версии и автооткатом; `--restore` для отката
- Глоссарий терминов, тон «вы», унификация терминологии (папка/каталог, тариф, промпт)
- Валидатор `check.mjs --strict` (полнота, плейсхолдеры, мусор) — готов для CI
