# SAFETY.md — что важно знать перед установкой

Это **не официальный продукт** Z.ai. Проект поддерживается сообществом и не связан
с Beijing Knowledge Atlas Technology (Z.ai).

## Что делает установщик

1. Копирует `/Applications/ZCode.app` → `work/backup/` (полный бэкап для отката).
2. Заменяет `Contents/Resources/app.asar` на русифицированную сборку (atomically).
3. Снимает quarantine-атрибуты (`xattr -cr`) и переподписывает приложение **ad-hoc**
   (`codesign --force --deep --sign -`).
4. Перезапускает ZCode. Если приложение не завелось — автоматически возвращает
   оригинальный asar и перезапускает снова.

## Риски

- **Подпись**: после патча подпись Developer ID (Z.ai) заменяется ad-hoc. Локально
  приложение работает; macOS может заново запросить разрешения TCC (запись экрана,
  универсальный доступ) и показать «не удалось проверить разработчика» при первом
  запуске из новых источников.
- **Обновления**: обновление ZCode затирает патч — просто повторите установку для
  новой версии (после пересборки под неё).
- **Целостность asar**: патч меняет содержимое архива. В ZCode 3.10.1 fuse
  `EnableEmbeddedAsarIntegrityValidation` отключён — приложение стартует. В будущих
  версиях вендор может его включить, тогда потребуется другой способ установки.
- **Гарантии нет**: патч предоставляется «как есть», без гарантий. Восстановление —
  `bash tools/restore.sh` (возвращает бэкап байт-в-байт).

## Что проект НЕ делает

- Не отправляет данные куда-либо; все скрипты работают локально.
- Не модифицирует исполняемые файлы Electron, не встраивает код в приложение
  помимо словарей и регистрации локали (6 файлов: 4 рендерер-чанка + 2 main-чанка).
- Не трогает разделы встроенного браузера, учётные данные и пользовательские данные.
